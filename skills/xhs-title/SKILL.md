# 小红书标题公式 (XHS Title Formula)

从 75 个验证过的爆款公式中匹配合适的小红书标题。

## 触发方式
- /小红书标题
- "帮我起个小红书标题"
- "小红书标题公式"

## 工作流程

1. 了解内容主题和核心卖点
2. 从 75 个公式中匹配 3-5 个合适的
3. 解释为什么选这个公式
4. 生成标题方案

## 核心资源
- ../../4_expression/writing_style.md
- ../../4_expression/vocabulary_patterns.md
- ../../4_expression/hook_library.md（开头逻辑通用）

## 输出格式
- 每个方案附公式名称
- 解释匹配理由
- 不做空话
