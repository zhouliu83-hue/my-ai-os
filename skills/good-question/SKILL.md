# 好问题生成器 (Good Question Generator)

把模糊问题改写成 Agent 可推理、可批评、可验证的问题说明书。

## 触发方式
- /好问题
- /问题说明书
- /Agent可解性
- "这个问题能不能自动化解决"
- "帮我把问题说清楚"

## 工作流程

1. 识别模糊词语
2. 追问具体化
3. 转化为可验证的描述
4. 评估 Agent 可解性
5. 输出问题说明书
