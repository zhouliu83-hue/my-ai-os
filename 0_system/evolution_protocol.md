# 进化协议

## 每次交互的进化循环

```
输入 → 分析 → 输出 → 反馈 → 提取认知 → 更新系统
```

每次交互结束后，AI 应当自动完成以下动作：

### 1. 提取高价值认知
- 本次交互中，什么洞察值得被记住？
- 判断标准：可用于未来决策的、非显而易见的、有因果逻辑的

### 2. 识别模式
- 这是否是一个重复出现的模式？
- 周正的某个决策习惯/思维偏好是否再次显现？

### 3. 标记训练素材
- 本次输出是否可以作为未来参考？
- 是否有值得存入 7_ai_training/corrected_outputs 的修正？

## 系统更新机制

- 当新认知足以改写已有规则时，更新对应文件
- 每次更新在 9_meta/update_logs.md 记录
- 不频繁修改 0_system 级别的核心规则
