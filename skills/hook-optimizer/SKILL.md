# 开头优化 (Hook Optimizer)

按照开头的 5 种类型诊断和优化短视频开头。

## 触发方式
- /hook
- /优化开头
- "开头怎么写"
- "帮我优化开头"

## 5 种开头类型（轮换使用，连续 5 篇不重复）

1. **反常识断言** — "很多人都以为 X，其实..."
2. **反问题质问** — "你有没有想过，为什么..."
3. **悬念故事** — "1793 年，马戛尔尼带着 600 箱礼物来到北京..."
4. **认知威胁** — "如果你还在用 X 方法，你可能正在..."
5. **数据冲击** — "99% 的人都不知道..."
