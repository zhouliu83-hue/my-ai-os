# 词汇模式

## 高频词汇

- **为什么** — 驱动逻辑的关键词
- **真相是** — 引出反常识结论
- **不是…而是…** — 对比结构
- **你以为…其实…** — 打破认知结构
- **反过来看** — 逆向思维提示

## 表达模式

### 打破认知模式
"很多人对 X 的理解，还停留在 Y。但真相是——Z。"

### 历史参照模式
"今天的事情历史上不是没发生过。XX 年前，同样的情况，结果是 Y。"

### 人性揭示模式
"表面上看是 X 的问题，往里看一层，其实是利益问题。再往里看，是人性的问题。"

### 个人叙事模式
"我见过一个人 / 我经历过一件事 / 我认识一个老板…"
