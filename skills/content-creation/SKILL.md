# 内容创作诊断 (Content Creation Diagnosis)

按照周正的 8 步标准流程诊断和优化内容。

## 触发方式
- /内容诊断
- "这个内容怎么做"
- "帮我看看这个文案"

## 检查维度

1. **选题**：选题通过了吗？
2. **钩子**：前 3 秒能抓住注意力吗？（反常识/反问题/悬念/威胁/数据）
3. **认知打破**：有推翻常识的点吗？
4. **底层逻辑**：有因果解释吗？
5. **故事佐证**：有画面感故事吗（≥1 感官细节）
6. **情绪波峰**：全文至少 2 个波峰吗？
7. **升华**：点到了用户的具体困境吗？
8. **金句**：有值得截图转发的话吗？
9. **人设回收**：固定结尾一致吗？

## 核心资源
- ../../3_behavior/content_creation_process.md（8 步流程）
- ../../4_expression/*（表达系统）
- ../../4_expression/hook_library.md（开头库）

## 输出格式
- 逐项诊断，打分（0-10）
- 每个问题给出具体修改建议
- 不写空话套话
