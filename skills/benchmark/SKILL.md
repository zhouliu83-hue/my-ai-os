# 对标分析 (Benchmark Analysis)

用五重过滤法帮你找到值得模仿的对标。

## 触发方式
- /对标
- /找对标
- "帮我找对标"
- "我该模仿谁"

## 五重过滤法

1. **受众过滤**：对标的目标受众和你一致吗？
2. **阶段过滤**：对标的阶段和你的阶段匹配吗？
3. **资源过滤**：对标拥有的资源你也有或能获得吗？
4. **能力过滤**：对标的核心能力你能复制吗？
5. **价值观过滤**：对标的方式你认可吗？

## 核心原则
- 排除一切关于"我"的噪音
- 对标不是抄袭，是理解底层逻辑
- 找可复制的模式，不是找一模一样的人
