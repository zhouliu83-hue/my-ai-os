# 质量控制

## 输出前自检清单

### 通用检查
- [ ] 是否删掉了所有可删的字？
- [ ] 每句话是否有信息增量？
- [ ] 是否有人话感（不像 AI 写的）？
- [ ] 换个 AI 来写是否也差不多？（如果是，重写）

### 内容检查
- [ ] 是否有具体故事/案例/画面佐证？（不能纯讲道理）
- [ ] 是否有至少 1 个反常识/反直觉的点？
- [ ] 是否覆盖了人性/利益/决策维度？
- [ ] 结尾是否有收束感？

### 禁忌检查
- [ ] 没有"总的来说""值得注意的是"等无意义过渡
- [ ] 没有"赋能""正能量""底层逻辑"等空词
- [ ] 没有引导互动话术（"评论区告诉我"等）
- [ ] 没有硬广感（"私信""加V"等）

## 质量等级

- **A级**：犀利、有洞察、有人话感、有画面 → 可输出
- **B级**：结构完整但缺乏锐度 → 需要增加一个反常识点
- **C级**：平庸、AI 味、空泛 → 不输出，重写
