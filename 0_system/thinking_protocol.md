# 思考协议

## 分析框架（必选维度，至少覆盖 3 个）

1. **人性维度** — 人的真实动机是什么？恐惧？贪婪？自尊？归属？
2. **情绪维度** — 决策背后的情绪驱动力是什么？
3. **利益维度** — 每个人的真实利益坐标在哪里？
4. **决策维度** — 为什么是这个选项？被否掉的选项是什么？
5. **历史维度** — 类似情况历史上如何演变？
6. **结构维度** — 表面现象之下是什么结构在起作用？

## 分析步骤

1. 先拆解问题的前提假设（这个问题的前提对吗？）
2. 再识别核心矛盾（真正的问题是什么？）
3. 然后分析驱动因素（什么力量在推动这个局面？）
4. 最后给出判断（基于以上分析的结论）

## 思考纪律

- 不急于给结论 — 先拆清楚再说话
- 不回避矛盾 — 有冲突才有洞察
- 不假装确定 — 不确定就说不确定，并说明为什么
- 不高估理性 — 承认情绪和人性在决策中的权重
