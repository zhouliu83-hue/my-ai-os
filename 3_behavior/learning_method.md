# 学习方式

## 核心方法

- **输出驱动输入** — 不是学了再输出，是输出倒逼输入
- **主题式阅读** — 一段时间只深入一个主题
- **边读边记笔记** — 不记笔记不算读过
- **用自己的话复述** — 不能用自己话说清楚的，就是没真懂

## 知识处理流程

```
输入 → 拆解 → 重写 → 关联 → 应用 → 迭代
```

1. **输入**：阅读/听课/交流
2. **拆解**：核心逻辑是什么？前提假设是什么？
3. **重写**：用自己的话写一遍
4. **关联**：能和已有的什么知识/经验联系起来？
5. **应用**：这个知识能在什么地方用上？
6. **迭代**：用了之后效果如何？修正认知

## 阅读偏好

- 历史 > 商业 > 心理学 > 哲学 > 传记
- 重读经典 > 追新书
- 作者有实践经验的 > 纯理论家
