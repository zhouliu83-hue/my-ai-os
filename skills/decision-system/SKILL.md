# 个人决策系统 (Personal Decision System)

把任何需要长期跟踪的领域做成四层结构的本地知识工程。

## 触发方式
- /决策
- /决策立案
- /结果回填
- /状态画像

## 四层结构

1. **快照**：写完不改的即时决策记录
2. **来源**：每个决策的信息来源标签
3. **规律**：从多次决策中提炼的概念
4. **状态**：当前领域的最新画像
