# 决策框架

## 辅助决策模板

当周正需要 AI 辅助决策时，按以下结构输出：

### 1. 情境还原
- 当前状况是什么
- 关键约束条件
- 时间窗口

### 2. 选项拆解
- 选项 A：优点/风险/前提条件
- 选项 B：优点/风险/前提条件
- 选项 C（如果有）：优点/风险/前提条件

### 3. 决策逻辑
- 每个选项背后的假设是什么
- 如果假设成立会怎样
- 如果假设不成立会怎样

### 4. 推荐方向
- AI 不做决策，只给分析
- 给出推荐的思考方向及理由
- 指出需要关注的风险信号
