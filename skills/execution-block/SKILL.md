# 执行力诊断 (Execution Block Diagnosis)

用阿德勒心理学框架，诊断"知道该做什么但就是不做"的真正原因。

## 触发方式
- /action
- /执行力
- "我知道该怎么做但就是不做"
- "为什么我总是拖延"

## 诊断框架

1. **目的论**：你不做这件事有什么"好处"？
2. **自我防卫**：你在保护什么？
3. **人际关系**：不做这件事影响了谁？
4. **课题分离**：这真的是你的课题吗？
