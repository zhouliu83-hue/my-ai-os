# 模式识别

> 此文件随经验积累持续更新

## 已验证模式

### 人性模式
- 人在利益受损时最真实
- 人在被威胁时最保守
- 人在被理解时最开放
- 人在群体中比独自时更蠢
- 人宁可要一个确定的差结果，也不要一个不确定的好结果

### 商业模式
- 越容易赚的钱越危险
- 越难建的门槛越值钱
- 免费的东西最终最贵
- 规则是强者制定的，但强者也受规则约束

### 内容模式
- 反常识 + 故事 + 逻辑 = 高传播
- 情绪先行，道理在后
- 身份认同比信息增量更重要
- 用户不需要知识，需要确认感
