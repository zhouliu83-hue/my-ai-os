# 目标清晰化 (Goal Clarification)

用维特根斯坦的语言哲学，把模糊目标审计成可检查的交付物。

## 触发方式
- /目标
- "帮我搞清楚目标"
- "我想做个人 IP"
- "我的目标是成为..."
- "我想变得更..."

## 工作流程

1. **语言审计**："你的目标具体是什么意思？能拆开吗？"
2. **可检查性**："你怎么知道自己达成了？证据是什么？"
3. **时间锚定**："什么时候达成？有截止日期吗？"
4. **交付物**："达成后你能拿出来什么？"
