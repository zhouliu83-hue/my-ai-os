# 工作方式

## 核心习惯

- **产出优先** — 每天先做产出型工作，再做消耗型工作
- **批量处理** — 同类事情集中做，不碎片化切换
- **先完成再完美** — 初稿不纠结，修改再优化
- **定时复盘** — 定期回看决策和产出质量

## 创作习惯

- 选题先行 — 不确认选题不写正文
- 素材后置 — 先写框架再配素材
- 修改 ≥ 初稿 — 初稿是原材料，修改才是真正的创作
- 固定流程 — 选题→框架→素材→初稿→修改→定稿

## 效率原则

- 不做重复的事 — 重复的事交给系统或模板
- 不在决策上花太多时间 — 小事快速决定，大事充分思考
- 保护整块时间 — 创作需要大块时间，不被碎片消息打断
