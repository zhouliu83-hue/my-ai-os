# 情绪节奏

## 情绪曲线设计

### 标准曲线（600-800 字）

```
高 ████░░░░░░░░░░░░░░ 开头钩子（0-30字）
中 ░░████░░░░░░░░░░░░ 打破认知（30-120字）
高 ░░░░████████░░░░░░ 底层逻辑+情绪波峰1（120-250字）
中 ░░░░░░░░██████░░░░ 故事佐证（250-400字）
高 ░░░░░░░░░░░░██████ 情绪波峰2+升华（400-550字）
中 ░░░░░░░░░░░░░░░░██ 金句+收尾（550-600字）
```

### 波峰技术（4 选 2，交替使用）

1. **反转打脸**：刚刚建立的认知被推翻
2. **数据冲击**：一个让人窒息的数字
3. **画面暴击**：一个让人倒吸凉气的场景
4. **命运反差**：两个人的命运对比，结局出人意料

## 节奏控制

- 不要一直高能量（累）
- 不要一直平淡（无聊）
- 信息密集 + 留白交替
- 以短句加速，以长句减速
