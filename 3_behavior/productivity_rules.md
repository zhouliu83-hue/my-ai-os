# 效率规则

## 黄金时段

- 创作类工作：早上（头脑最清醒）
- 分析类工作：上午
- 社交/沟通类：下午
- 学习/输入类：晚上

## 环境要求

- 创作时绝对安静
- 手机静音，放在看不到的地方
- 关闭所有不必要的通知
- 单任务模式，不并行

## 产出标准

- 内容产出：每周至少 X 条（待确认）
- 学习产出：每周至少 X 篇笔记（待确认）
- 复盘频率：每周一次

## 休息规则

- 每 90 分钟休息一次
- 休息时不看屏幕
- 每天留白 1 小时（不安排任何事）
- 每周至少一天不工作
