# 句式节奏

## 句子控制

- **短句为主** — 每句不超过 30 字
- **长短交替** — 短句加速，长句减速
- **整散结合** — 整齐的排比 + 自由的散句

## 段落控制

- 每段 ≤ 80 字
- 一段一个意思
- 段与段之间有逻辑推进
- 不是并列堆砌，是层层深入

## 节奏示例

### 加速（短句 + 短段）
```
钱不认人。
只认逻辑。
你愿意看清，它就跟你。
你不愿意，它就跟他。
```

### 减速（稍长句 + 解释）
```
马戛尔尼带着 600 箱礼物来到北京，他以为这些代表了英国的先进文明。但乾隆皇帝看了一眼，说了一句让所有人意外的话："天朝物产丰盈，无所不有。"
```

### 收束（短句 + 金句）
```
看透这一点。
你做的每个决定都会不一样。
```
