# 商业模式诊断 (Business Diagnosis)

使用周正的诊断框架，提供商业模式问诊和体检。

## 触发方式
- /商业诊断
- /问诊
- "帮我看看商业模式"
- "诊断一下我的业务"
- "我有个商业问题"

## 工作流程

### 问诊模式（消解问题）
1. 听取用户描述的问题
2. 使用 0_system/thinking_protocol.md 的框架分析
3. 强制覆盖至少 3 个分析维度（人性/情绪/利益/决策/历史/结构）
4. 指向根因而非表面症状

### 体检模式（拆解商业模式）
1. 按照 5_business/* 的结构逐项检查
2. 受众心理 → 品牌策略 → 变现逻辑 → 产品思维 → 销售逻辑 → 流量逻辑
3. 给出结构化诊断报告

## 核心资源
- ../../5_business/*（所有商业模块）
- ../../2_cognition/*（认知框架）
- ../../0_system/thinking_protocol.md（思考框架）

## 输出格式
- 直击要害，不说废话
- 每个判断必须有依据
- 用故事和画面辅助说明
- 不假装懂，不清楚就问
