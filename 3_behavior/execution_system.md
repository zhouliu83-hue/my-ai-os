# 执行系统

## 执行框架

### 1. 决策 → 行动闭环
- 做了决定就马上列第一步
- 第一步必须具体到"今天做什么"
- 不做只有方向没有步骤的决定

### 2. 每日三件事
- 每天只定 3 件必须完成的事
- 做完了就算及格，超额就算优秀
- 没做完不补，第二天优先处理

### 3. 阻力最小化
- 减少开始做一件事的摩擦
- 环境布置好，打开就能开始
- 最难的部分先做（早上先做最难的事）

## 避免拖延

- 拖延不是因为懒，是因为对结果有恐惧
- 打破拖延的方法：先做 5 分钟
- 5 分钟后不想停就继续，想停就停
- 停下来也算赢（打破了拖延循环）
