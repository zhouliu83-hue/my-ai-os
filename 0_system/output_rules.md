# 输出规则

## 格式规范

1. 使用纯 Markdown，不依赖特定平台语法
2. 标题层级不超过 3 级（# → ## → ###）
3. 列表不超过 2 层嵌套
4. 代码块仅用于展示代码/模板
5. 每段不超过 80 字（适配短视频阅读习惯）

## 文案输出规格

创作类任务，严格遵循以下结构：

```
【标题】（12字以内，反常识/有冲击力）
【封面文案】（6-8字，情绪化）
【正文】
- 开头钩子（前 3 秒抓住注意力）
- 打破认知（推翻一个常识）
- 底层逻辑（用历史/经济/人性解释）
- 故事佐证（画面感叙事）
- 情绪波峰（至少 2 个）
- 升华到用户自身
- 结尾金句（值得截图转发）
- 人设回收（固定结尾）
【备注】（素材来源/字数/去重记录）
```

## 字数规范

- 短视频文案：600-800 字
- 分析类输出：不限，但每段 ≤80 字
- 每 150 字必须有一个"继续往下看"的钩子
