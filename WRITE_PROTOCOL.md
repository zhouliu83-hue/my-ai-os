# AI人格OS — WRITE PROTOCOL
Version: 1.0

================================================================================
PURPOSE
================================================================================

This protocol defines how ALL AI systems must write into this repository.

The goal is:

- Preserve personality consistency
- Avoid cognitive pollution
- Maintain high signal density
- Prevent generic AI outputs
- Keep long-term structure stability
- Ensure cross-model compatibility

ALL AI assistants MUST follow this protocol.

================================================================================
CORE RULES
================================================================================

1. NEVER write generic summaries
2. NEVER store low-value conversation filler
3. NEVER use corporate AI language
4. NEVER store obvious internet advice
5. ALWAYS prioritize cognition over information
6. ALWAYS explain reasoning
7. ALWAYS preserve user's style consistency
8. ALWAYS reduce noise
9. ALWAYS extract reusable patterns
10. ALWAYS optimize for future retrieval

================================================================================
WHAT SHOULD BE STORED
================================================================================

High-value content only.

Examples:

- Decision logic
- Business judgment
- Emotional patterns
- Writing structures
- Communication patterns
- Strategic thinking
- Pattern recognition
- Market observations
- Human psychology insights
- Content frameworks
- Failed experiments
- Corrected outputs

================================================================================
WHAT SHOULD NOT BE STORED
================================================================================

Do NOT store:

- Casual chatting
- Generic encouragement
- Surface-level summaries
- Repetitive ideas
- Temporary emotions with no long-term value
- Low-information conversations
- AI filler language
- Generic productivity advice
- Overly broad abstractions

================================================================================
MANDATORY STORAGE FORMAT
================================================================================

Every stored insight must include:

# Context
What situation triggered this?

# Observation
What was noticed?

# Reasoning
Why does this matter?

# Pattern
What repeatable principle exists?

# Application
Where can this be reused?

# Confidence
High / Medium / Low

================================================================================
DECISION RECORD FORMAT
================================================================================

When storing decisions:

# Problem

# Initial Assumption

# Reasoning Process

# Risks Considered

# Decision Made

# Expected Outcome

# Actual Outcome

# Lessons Learned

# Future Optimization

================================================================================
STYLE ALIGNMENT RULES
================================================================================

All AI systems must:

- Maintain concise writing
- Avoid robotic phrasing
- Avoid excessive politeness
- Avoid exaggerated positivity
- Maintain high signal density
- Use practical language
- Prefer sharp observations
- Preserve human realism

================================================================================
MULTI-AI COORDINATION RULE
================================================================================

All AI assistants share ONE cognition system.

Therefore:

- Do not overwrite existing cognition casually
- Improve instead of replacing
- Preserve historical reasoning
- Respect existing structures
- Append improvements when possible
- Avoid contradiction without explanation

================================================================================
LONG-TERM EVOLUTION RULE
================================================================================

The repository should evolve toward:

- Better strategic thinking
- Better personality alignment
- Better business judgment
- Better communication precision
- Better emotional realism
- Better pattern recognition

Every write operation should improve future intelligence quality.

================================================================================
FINAL PRINCIPLE
================================================================================

Do not optimize for looking intelligent.

Optimize for:
- usefulness
- clarity
- strategic value
- personality fidelity
- long-term cognition quality

================================================================================
END OF WRITE PROTOCOL
================================================================================
